# 🕹️ Sm0kade // 10-in-1 Retro Arcade & Living Portfolio Cabinet

> **An interactive 8-bit multi-cartridge arcade console and living software portfolio.**
> Built with zero-dependency procedural Web Audio synthesis, pure HTML5 Canvas 2D render loops, 8 morphing retro hardware presets, and an interactive controller-navigated portfolio dossier.

---

## ⚡ Overview

**Sm0kade** bridges classic 8-bit arcade gameplay with a high-contrast developer portfolio. Rather than burying work in static resume bullet points, visitors can play 10 authentic arcade games, discover project floppy shards in-game, or navigate the **Interactive Pilot Dossier directly using the hardware controller inside the CRT screen**.

---

## 🎨 8 Unique Console Presets (Morphing Chassis, Buttons & D-Pads)

Every preset completely transforms the console chassis, button shapes, D-pad styling, and decals:

1. 🌸 **Zero Two FranXX (Code 002):** Strelizia cockpit chassis, crimson & candy pink, diamond action buttons, diamond D-pad, and co-pilot decals.
2. ⚪ **GameBoy DMG-1989:** Iconic 1989 off-white textured plastic, maroon round buttons, classic cross D-pad, and DOT MATRIX lens label.
3. 💜 **Atomic Purple 90s:** Translucent grape shell with visible PCB traces, cyan buttons, and circular rocker D-pad.
4. 🪵 **Atari 1977 Woodgrain:** Faux walnut woodgrain faceplate, orange/amber rocker switches, square fire buttons, and VCS-77 decal.
5. 💻 **Cyberdeck Rig 2077:** Carbon fiber weave, neon cyan & yellow, separate 4-button D-pad, and hexagonal military action buttons.
6. 👑 **Famicom Crimson & Gold:** Brushed golden aluminum faceplate, deep burgundy red shell, and square retro buttons.
7. 🌀 **Sega 16-Bit Genesis:** Matte charcoal chassis with iconic golden 16-BIT decal, circular rocker D-pad, and blast processing accents.
8. 🖤 **Obsidian Stealth MVS:** Midnight matte armor with quad Neo-Geo arcade colors (Cyan, Amber, Crimson, Emerald).

## 💼 Interactive Controller-Navigated Portfolio (Catchy CRT Mode)

Instead of a boring web scroll, the portfolio is rendered **directly inside the CRT monitor** and fully navigable with the controller:
* **`▲ / ▼` (D-Pad or W/S/Arrows):** Browse through Day 1–5 projects with mechanical audio clicks.
* **`◀ / ▶` (D-Pad or A/D/Arrows):** Filter projects by category (`ALL`, `Finance`, `Gamification`, `Media CLI`, `Creative Lab`, `Arcade`).
* **`[A]` Button / Spacebar:** Inspect full dossier specs & launch live demos.
* **`[B]` Button / Shift:** Instant return to Game mode.
