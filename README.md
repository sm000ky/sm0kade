# 🕹️ Sm0kade // 10-in-1 Retro Arcade & Living Portfolio Cabinet

> **An interactive 8-bit multi-cartridge arcade console and living software portfolio.**
> Built with zero-dependency procedural Web Audio synthesis, pure HTML5 Canvas 2D render loops, custom console shapes & color themes, and a modular plug-and-play cartridge architecture.

---

## ⚡ Overview

**Sm0kade** bridges classic 8-bit arcade gameplay with a high-contrast developer portfolio. Rather than burying work in static resume bullet points, visitors can play 10 authentic arcade games, discover project floppy shards in-game, or switch seamlessly into the **Hall of Fame Dossier** view.

### 🎮 The 10 Classic Cartridges
1. 🟡 **DEV LABYRINTH (Pac-Man Engine):** Classic target-AI maze. Blinky, Pinky, Inky, and Clyde with scatter/chase phases, power pellets, and floppy discs.
2. 👾 **BYTE INVADERS (Space Shooter):** Pilot the defense cannon, destroy waves of marching runtime errors, shoot the mystery tech UFO, and defend firewalls.
3. 🧱 **TECH BREAKOUT (Brick Smasher):** Deflect the energy ball through stacks of TypeScript, Python, Linux, and React bricks; smash golden bricks for data shards.
4. 🐍 **CYBER SNAKE (Matrix Snake):** Classic Nokia/arcade snake. Navigate the neon grid, gobble data nodes, dodge the perimeter, and grab portfolio floppy discs.
5. 🧩 **BLOCK STACKER (Tetris Engine):** Standard 10x20 matrix falling tetrominoes with classic rotations, ghost piece projection, line clear multipliers, and portfolio drops.
6. 🚀 **CYBER FLAP (Flappy Flight):** Physics-based rocket flight dodging scrolling server stacks. Addictive, high-velocity reflex test.
7. 🏓 **CYBER PONG (1972 Table Tennis):** Player vs AI paddle duel. First to 5 points wins; unlocks project spotlights on score.
8. ☄️ **ASTRO ROCKS (Vector Asteroids):** 360° inertia flight & laser blaster. Break floating space debris into smaller fragments.
9. 🏎️ **NEON RACER (Highway Drift):** 3-lane vertical speedway. Dodge oncoming traffic, activate turbo boost, and collect highway floppy shards.
10. 🧠 **MATRIX MEMORY (Pattern Recall):** 4-sector Simon Says neural test. Listen to tones, repeat the sequence, and expand developer memory.
